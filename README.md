# AI Resume Screening System

An AI-powered resume screening application using Python, NLP, Machine Learning, and Streamlit.

## Features
- Resume PDF Upload
- Resume Parsing
- NLP Text Cleaning
- Resume Classification
- Job Description Matching
- Match Score Prediction

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- NLP
- TF-IDF
- Logistic Regression

## Run Project

pip install -r requirements.txt

python train_model.py

streamlit run app.py
